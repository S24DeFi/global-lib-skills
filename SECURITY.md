# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private vulnerability reporting instead: the **Security** tab of this repository, then **Report a vulnerability**. You can also email andrespencer.dev@gmail.com.

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement within 3 business days.

## Supported versions

Only the latest commit on `main` is supported. Fixes land there.

## Scope

The Claude Code plugins and skills in this repository.
